Extensions for Visual Studio Code

Three extensions for working with LaTeX and with participatory budgeting data. They are published on the Visual Studio Marketplace under the publisher ID DominikPeters (publisher page). Each page below explains what the extension does and how to use it.

TeXpresso

Live LaTeX preview beside your source, with SyncTeX in both directions.

How it works and how to use it · VS Code Marketplace

Bib Indexer

Search all your .bib files and merge matching entries from a sidebar.

How it works and how to use it · VS Code Marketplace

Pabulib (.pb)

Highlighting, validation and completions for participatory budgeting .pb files.

How it works and how to use it · VS Code Marketplace

Installing an extension

Open the Extensions view in VS Code (Ctrl/Cmd+Shift+X), search for the extension name and select Install, or use the Marketplace links above. Source code and issue trackers are linked from each extension's page.
